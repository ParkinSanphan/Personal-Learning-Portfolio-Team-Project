วิธีทดลองใช้งาน (Usage Guide)

    จัดการข้อมูลส่วนตัว (Personal Information)

    ในการ์ด Personal Information Portfolio 1 ให้กรอกข้อมูลโปรไฟล์ของคุณ

    กดปุ่ม Submit Profile เพื่อบันทึก

    ข้อมูลจะนำไปอัปเดตและแสดงผลในส่วน HELLO, I AM และ About Me ที่ด้านล่างทันที

    เพิ่มรายการผลงาน (Portfolio Items)

    เลื่อนลงมาที่ฟอร์ม Portfolio Item

    กรอกรายละเอียดผลงาน และระบุ Evidence Link (ต้องขึ้นต้นด้วย https://)

    กดปุ่ม Submit Item เพื่อเพิ่มผลงานเข้าสู่รายการแสดงผลด้านล่าง

    ทดสอบการทำงานร่วมกัน (Portfolio 2 & Utilities)
