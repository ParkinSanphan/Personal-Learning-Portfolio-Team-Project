# Personal Learning Portfolio

เว็บแอปพลิเคชันสำหรับสร้างและจัดเก็บแฟ้มสะสมผลงานการเรียนรู้ รองรับการสร้างโปรไฟล์หลายคน รวมถึงการสำรองและกู้คืนข้อมูลผ่านโค้ด JSON

## วิธีเปิดใช้งานเว็บในเครื่อง (Localhost)

เนื่องจากตัวเว็บมีการเชื่อมต่อกับ PHP เพื่ออ่านและเขียนไฟล์ข้อมูล ทำให้ไม่สามารถดับเบิลคลิกเปิดไฟล์ `index.html` โดยตรงได้ ให้เปิดผ่านเซิร์ฟเวอร์จำลองของ PHP ตามขั้นตอนนี้:

1. เปิดโปรแกรม Terminal (หรือเปิดผ่านเมนู Terminal ใน VS Code) แล้วเข้าไปยังโฟลเดอร์หลักของโปรเจกต์
2. รันคำสั่งเปิดเซิร์ฟเวอร์:
   ```bash
   php -S localhost:8000
   ```
3. เปิดเบราว์เซอร์แล้วเข้าไปที่ `http://localhost:8000`
4. เมื่อใช้งานเสร็จ ให้กลับมาที่หน้าต่าง Terminal แล้วกด `Ctrl + C` เพื่อปิดเซิร์ฟเวอร์

## คู่มือการใช้งาน

### 1. การสร้างข้อมูลส่วนตัว
1. เลื่อนไปที่ส่วน **Personal information portfolio** แล้วกรอกข้อมูลให้ครบทุกช่อง (ชื่อ อีเมล เบอร์โทร สิ่งที่ชอบ สิ่งที่เคยลองทำ และสิ่งที่สนใจ)
2. กดปุ่ม **Submit Profile** เพื่อบันทึก (หรือกด **Reset** หากต้องการล้างข้อมูลที่พิมพ์ไว้)
3. ข้อมูลโปรไฟล์ที่สร้างใหม่จะไปแสดงผลในส่วนแสดงผลด้านล่างทันที

### 2. การเพิ่มรายการผลงาน
> หมายเหตุ: ก่อนเพิ่มผลงาน ต้องสร้างหรือเลือกโปรไฟล์เจ้าของผลงานก่อนเสมอ

1. กรอกรายละเอียดในส่วน **Add a Portfolio Item**
   * ช่อง **Skills** และ **Evidence** หากมีหลายรายการ ให้พิมพ์คั่นด้วยเครื่องหมายลูกน้ำ `,` (เช่น `HTML, CSS, JavaScript`)
   * ช่อง **Reflection** ให้กรอกรายละเอียดสิ่งที่ได้ทำ สิ่งที่ได้เรียนรู้ อุปสรรค และแผนขั้นต่อไป
2. กดปุ่ม **Submit Item** ระบบจะบันทึกและแสดงรายการผลงานใหม่ต่อท้ายในโปรไฟล์นั้นทันที

### 3. การสลับดูโปรไฟล์
* ในหัวข้อ **Portfolios** จะแสดงรายชื่อโปรไฟล์ทั้งหมดที่มีอยู่ในระบบพร้อมจำนวนผลงาน
* สามารถคลิกเลือกชื่อที่ต้องการเพื่อสลับดูข้อมูลและผลงานของแต่ละคนได้เลย

### 4. การส่งออกและนำเข้าข้อมูล (Export / Import JSON)

**การส่งออกข้อมูล (Export JSON)**
ใช้สำหรับดึงข้อมูลทั้งหมดในระบบออกมาเก็บสำรองไว้ หรือส่งต่อให้คนอื่น:
1. กดปุ่ม **Export JSON** ด้านล่างสุดของหน้าเว็บ
2. หน้าต่าง Popup จะเปิดขึ้นมาพร้อมโค้ด JSON ของข้อมูลทั้งหมด
3. กดปุ่ม **Copy JSON** เพื่อคัดลอกโค้ดลงคลิปบอร์ด แล้วกด **Close** เพื่อปิดหน้าต่าง

**การนำเข้าข้อมูล (Import JSON)**
ใช้สำหรับนำข้อมูลที่สำรองไว้ หรือข้อมูลของคนอื่นเข้ามาในระบบ:
1. กดปุ่ม **Import JSON** ด้านล่างสุดของหน้าเว็บ
2. วางโค้ด JSON ลงในช่องข้อความที่กำหนด
3. กดปุ่ม **Confirm / Import**
   * **กรณีข้อมูลถูกต้อง:** ระบบจะนำข้อมูลใหม่เข้าไปรวมกับข้อมูลเดิม (ถ้า `id` ซ้ำจะอัปเดตทับของเดิม แต่ถ้าเป็น `id` ใหม่จะเพิ่มต่อท้ายให้) จากนั้นหน้าเว็บจะอัปเดตข้อมูลใหม่ทันทีโดยไม่ต้องกดรีเฟรช
   * **กรณีโค้ดผิดรูปแบบ:** ระบบจะขึ้นแถบแจ้งเตือนสีแดงและไม่บันทึกข้อมูล เพื่อป้องกันไม่ให้ข้อมูลเดิมในระบบเสียหาย
