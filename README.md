วิธีเปิดใช้งานเว็บไซต์ (Getting Started)
   
    1.ดาวน์โหลด หรือ Clone Repository
    git clone https://github.com/ParkinSanphan/Personal-Learning-Portfolio-Team-Project.git

    2.เปิดโฟลเดอร์โปรเจกต์ บนเครื่องของคุณ

    3.เปิดหน้าเว็บ: คลิกขวาที่ไฟล์ index.html แล้วเลือกเปิดด้วยเว็บเบราว์เซอร์ (Google Chrome, Microsoft Edge หรือ Firefox)

วิธีทดลองใช้งาน (Usage Guide)

    1.จัดการข้อมูลส่วนตัว (Personal Information)

    2.ในการ์ด Personal Information Portfolio 1 ให้กรอกข้อมูลโปรไฟล์ของคุณ

    3.กดปุ่ม Submit Profile เพื่อบันทึก

    4.ข้อมูลจะนำไปอัปเดตและแสดงผลในส่วน HELLO, I AM และ About Me ที่ด้านล่างทันที

    5.เพิ่มรายการผลงาน (Portfolio Items)

    6.เลื่อนลงมาที่ฟอร์ม Portfolio Item

    7.กรอกรายละเอียดผลงาน และระบุ Evidence Link (ต้องขึ้นต้นด้วย https://)

    8.กดปุ่ม Submit Item เพื่อเพิ่มผลงานเข้าสู่รายการแสดงผลด้านล่าง

    9.ทดสอบการทำงานร่วมกัน (Portfolio 2 & Utilities)

    10.Portfolio 2: ทำซ้ำขั้นตอนเดิมกับการ์ด Personal Information Portfolio 2 ที่อยู่ทางฝั่งขวาเพื่อทดสอบระบบจัดเก็บแยกส่วน
